# FIT & LIFT GYM — Landing Page

صفحة هبوط احترافية لجيم **Fit & Lift** ببنها. مبنية بـ **Next.js 14 + Tailwind CSS + GSAP**، ثنائية اللغة (عربي RTL / إنجليزي LTR) بثيم أسود وأخضر.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # نسخة الإنتاج
npm run start
```

## المميزات
- تبديل لغة فوري (عربي/إنجليزي) مع اتجاه الصفحة RTL/LTR وحفظ الاختيار.
- أنيميشن GSAP: دخول الـ Hero، عدّاد الأرقام، وظهور العناصر عند التمرير + parallax.
- أقسام: Hero، إحصائيات، من نحن، الخدمات، جدول الحصص، المدربين، الاشتراكات، آراء الأعضاء، تواصل + خريطة، فوتر.
- فورم الحجز بيفتح واتساب تلقائياً على رقم الجيم.
- متجاوب بالكامل مع الموبايل.

## تعديل المحتوى
كل النصوص والأرقام والأسعار في ملف واحد: **`lib/content.ts`**
- `business` → أرقام التليفون، الإيميل، السوشيال، رابط الخريطة.
- `dict` → كل النصوص بالعربي والإنجليزي (Hero، الخدمات، الأسعار، الجدول... إلخ).

> ملاحظة: الأسعار والجداول وأسماء المدربين قيم مبدئية جاهزة للتعديل — البيانات الأساسية (العنوان/الأرقام/الإيميل) حقيقية من صفحة الجيم.

## الصور
التصميم معتمد على الجرافيك والتدرجات عشان يشتغل بدون صور خارجية. لإضافة صور حقيقية للجيم: ضيفها في `public/` واستبدل البلوكات الرسومية في `Hero.tsx` / `About.tsx` / `Trainers.tsx`.
